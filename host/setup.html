กำลังตรวจ… โมเดล GPU

1) ติดตั้ง engine + โมเดล

เปิด terminal แล้วรัน (ดาวน์โหลด torch ~2.3 GB + โมเดล ~9 GB ครั้งแรกครั้งเดียว):

bash engine/setup.sh

ถ้ามีไฟล์ SANA1.5_1.6B_1024px.pth ในเครื่องอยู่แล้ว ใช้การแปลงแทนการโหลด transformer ได้:

bash engine/setup.sh --from-pth "/path/to/SANA1.5_1.6B_1024px.pth"

2) เปิดโปรแกรม

bash electron/linux-setup.sh

ครั้งแรกจะติดตั้ง Electron (~100 MB) แล้วเปิดหน้าต่างโปรแกรมให้อัตโนมัติ
